The format

One row per session, with this header row. Only date and kind are needed.

date,kind,title,distance_km,duration_min,pace,description
2026-11-04,threshold,3 x 10 min threshold,10,,5:05,"2 km warm-up; 3 x 10 min, 2 min jog; cool-down"
2026-11-05,rest,Rest,,,,
  • date: YYYY-MM-DD.
  • kind: {% for k, v in kinds.items %}{{ k }}{% if not forloop.last %}, {% endif %}{% endfor %}.
  • distance_km: the whole session, warm-up and cool-down included. duration_min: for sessions planned by time.
  • pace: free text, such as 5:05 or 6:10-6:30.
  • A description with commas goes in double quotes. Commas, semicolons or tabs between columns all work.
